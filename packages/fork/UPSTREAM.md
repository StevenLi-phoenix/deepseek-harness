# fork upstream ledger

This fork keeps upstream `packages/` untouched. Fork-local code lives in `packages/fork/*` (new packages) and `/fork` (deployment files). When an upstream package must change, copy it into `packages/fork/` under a new name (`@deepseek-ai/dsh-fork-<name>`), record it here, and disable the upstream row in the profile patch instead of editing upstream files.

## Upgrade procedure

1. `git fetch upstream --tags` and fast-forward `master` to the new upstream tag.
2. For each copied package above: `git diff <upstream commit>..<new tag> -- <upstream path>` and port the relevant changes into the fork copy; update its row.
3. `git switch fork/main && git merge master`; resolve conflicts in the files listed under "Upstream files touched".
4. `pnpm install && pnpm run gen-tsconfig-paths && pnpm run build:artifacts`, then `pnpm exec vitest run packages/fork` and the fork gates in [`/fork/README.md`](../../fork/README.md).
5. Bump the version of every `packages/fork/*` manifest to the root version (the constraints gate requires it) and update the Baseline table.
