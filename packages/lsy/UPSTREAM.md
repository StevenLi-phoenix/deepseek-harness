# lsy upstream ledger

This fork keeps upstream `packages/` untouched. Fork-local code lives in `packages/lsy/*` (new packages) and `/lsy` (deployment files). When an upstream package must change, copy it into `packages/lsy/` under a new name (`@deepseek-ai/dsh-lsy-<name>`), record it here, and disable the upstream row in the profile patch instead of editing upstream files.

## Upstream files touched

Every edit outside `packages/lsy/` and `/lsy` is listed here so an upgrade can re-apply it.

| File | Change |
|---|---|

| `scripts/product-package-policy.ts` | One `optional` entry per `packages/lsy/*` package |
| `pnpm-lock.yaml` | Workspace entries for `packages/lsy/*` |

## Upgrade procedure

1. `git fetch upstream --tags` and fast-forward `master` to the new upstream tag.
2. For each copied package above: `git diff <upstream commit>..<new tag> -- <upstream path>` and port the relevant changes into the fork copy; update its row.
3. `git switch lsy/main && git merge master`; resolve conflicts in the files listed under "Upstream files touched".
4. `pnpm install && pnpm run gen-tsconfig-paths && pnpm run build:artifacts`, then `pnpm exec vitest run packages/lsy` and the lsy gates in [`/lsy/README.md`](../../lsy/README.md).
5. Bump the version of every `packages/lsy/*` manifest to the root version (the constraints gate requires it) and update the Baseline table.
